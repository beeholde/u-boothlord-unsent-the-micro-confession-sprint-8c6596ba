One two-part micro-confession, written exactly as it was typed and never sent: a To: line naming who it was meant for, and the unsent message itself, one line, with no explanation after it.

## Run it

```sh
python3 main.py
```

This writes the confession to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
